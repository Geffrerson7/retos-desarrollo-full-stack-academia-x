# 🚀 Retos de Desarrollo Full Stack - Academia X

¡Bienvenido a mi repositorio de aprendizaje! En este espacio comparto la resolución de los retos, proyectos y prácticas que voy realizando a lo largo del curso **Desarrollador Full Stack** en **Academia X**. 

El objetivo de este repositorio es documentar mi progreso, consolidar mis conocimientos en tecnologías web y mantener un registro de mi evolución técnica tanto en el Frontend como en el Backend y Cloud computing.

---

## 📂 Estructura del Repositorio

El proyecto está organizado según las clases maestras del plan de estudios:

### 🌐 Frontend & Fundamentos
*   **`Clase Maestra de HTML/`**: Estructura semántica, formularios, SEO básico y accesibilidad web.
*   **`Clase Maestra de JavaScript/`**: Lógica de programación con JS Moderno (ES6+), manipulación del DOM y asincronía.
*   **`Clase Maestra de React/`**: Creación de interfaces de usuario interactivas, gestión de estados, hooks y componentes.

### ⚙️ Backend & Bases de Datos
*   **`Clase Maestra de Node.js/`**: Creación de APIs, servidores con Express y entorno de ejecución del lado del servidor.
*   **`Clase Maestra de SQL/`**: Diseño de bases de datos relacionales, consultas avanzadas (queries) y persistencia de datos.

### ☁️ Despliegue & Cloud (DevOps)
*   **`Clase Maestra de Hosting/`**: Fundamentos de despliegue de aplicaciones, dominios y servidores web tradicionales.
*   **`Clase Maestra de AWS/`**: Configuración de servicios en la nube de Amazon Web Services (EC2, S3, etc.) y arquitectura cloud.
